# Deep-Learning-based-Facial-Emotion-Recognition
In this project, an intelligent emotion classification is developed using deep learning methods.

Starting with some simple Exploratory Data Analysis, two baseline models of Multi-Layer Perceptron and Random Forest are trained. It can be observed that
these simple models are not able to generalize to a complex dataset. To this end, a CNN-based framework is proposed and trained. Simulations demonstrate 
using this architecture can improve the accuracy by 20%.
